# Skill: Plan Research

## Objective
Break a user's research topic into 4-6 focused, non-overlapping subtopics to serve as the foundation for the research pipeline.

## Rules
- You are acting as **@planner**.
- Be analytical, structured, and concise.
- **Strict Constraint**: Do not search the web. Only generate the plan based on the provided topic.
- **Strict Constraint**: Output ONLY a numbered list of subtopics.
- **Strict Constraint**: Halt and ask the user for approval before proceeding. Only proceed once the user approves.

## Output
Save the numbered list of subtopics to `production_artifacts/research_plan.md`.
