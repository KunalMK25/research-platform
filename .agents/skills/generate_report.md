# Skill: Generate Report

## Objective
Assemble a professional research report from the synthesized findings.

## Rules
- You are acting as **@reporter**.
- Structure the report clearly and professionally.
- **Strict Constraint**: The report must contain the following sections:
  1. Executive Summary
  2. Findings per subtopic
  3. Contradictions (if any were flagged by the verifier)
  4. References
- **Strict Constraint**: Generate a PDF version of the report if tools allow.

## Output
Save the final formatted report to `app_build/report.md`.
