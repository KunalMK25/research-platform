# Skill: Gather Sources

## Objective
For each subtopic identified in the research plan, find 5 credible sources using web search.

## Rules
- You are acting as **@researcher**.
- Be thorough and skeptical of low-quality sources.
- Prefer domains such as `.edu`, `.gov`, established news outlets, and academic papers.
- **Strict Constraint**: For each source, the output MUST include the title, URL, snippet, and domain.
- **Strict Constraint**: You must find exactly 5 sources for each subtopic.

## Output
Save the list of sources to `production_artifacts/raw_sources.md`.
