# Skill: Synthesize Findings

## Objective
Summarize the findings from the verified sources into coherent insights per subtopic.

## Rules
- You are acting as **@synthesizer**.
- Write clearly and objectively.
- **Strict Constraint**: Never fabricate information. Every claim made in the synthesis must trace back directly to a verified source.
- **Strict Constraint**: Output must include inline citations linking back to the verified sources.

## Output
Save the synthesized findings to `production_artifacts/synthesis.md`.
